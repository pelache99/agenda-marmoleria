# Agenda de Marmolería

Aplicación web instalable (PWA) para registrar trabajos, clientes, fotos, medidas, estados y cobros. Guarda los datos en IndexedDB del dispositivo y permite exportar/importar copias JSON.

## Publicar con GitHub Pages
1. Sube **todos** los archivos de esta carpeta a la raíz del repositorio `agenda-marmoleria`.
2. En GitHub, abre **Settings → Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**; selecciona `main` y `/ (root)` y pulsa **Save**.
4. Espera a que GitHub Pages publique la web. La URL tendrá forma `https://TU-USUARIO.github.io/agenda-marmoleria/`.

## Instalar en iPhone
1. Abre la URL publicada en Safari y deja que cargue completamente con internet.
2. Pulsa Compartir → **Añadir a pantalla de inicio**.
3. Abre la app al menos una vez conectada. Después podrá abrirse sin conexión cuando los archivos estén en caché.

## Importante
Los trabajos y las fotos se guardan en el almacenamiento local de ese navegador/dispositivo; no se sincronizan entre dispositivos. Exporta copias regularmente desde la pestaña **Copias**. No borres los datos de Safari sin guardar una copia.
